# Smart Calculator

## Project Description
Smart Calculator is a simple calculator application developed using Python and Tkinter.

## Objective
To create a user-friendly calculator that performs basic mathematical calculations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Square Root
- Clear button

## Technologies Used
Python
Tkinter

## Conclusion
This project helps demonstrate the use of Python and Tkinter to create a simple graphical user interface application.
